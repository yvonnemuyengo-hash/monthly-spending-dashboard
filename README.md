# Monthly Spending Dashboard (2020–2025)

A responsive, static website for exploring income, expenditure, surplus, savings, and investments from a supplied monthly spending dataset. Amounts are in Indian rupees (₹).

## Publish with GitHub Pages
1. Open the repository **Settings**.
2. Choose **Pages** from the left sidebar.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then click **Save**.
5. Wait for the Pages deployment to finish. Your site URL will be shown in the Pages section.

## Data notes
- The 2025 figures cover January through September only.
- Savings and investments are displayed as separate categories, as they were in the workbook.
- Review category totals against the original workbook before relying on them for formal reporting.
